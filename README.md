# TypeScript 테트리스 (Web Tetris)

TypeScript로 제작된 현대적인 규칙의 웹 기반 테트리스 게임입니다. 모듈형 구조로 설계되었으며, 현대 테트리스의 표준 시스템들을 포함하고 있습니다.

## 🚀 시작하기

이 프로젝트는 TypeScript로 작성되었으므로, 실행을 위해서는 자바스크립트로의 컴파일 과정이 필요합니다.

### 1. 의존성 설치
```bash
npm install
```

### 2. 프로젝트 빌드
```bash
npm run build
```
빌드가 완료되면 `js/` 폴더에 자바스크립트 파일들이 생성됩니다.

### 3. 게임 실행
- `index.html` 파일을 브라우저에서 엽니다.
- (권장) VS Code의 `Live Server` 확장 프로그램 등을 사용하여 로컬 서버에서 실행하는 것이 좋습니다.

## 🎮 조작 방법

| 키보드 입력 | 동작 |
| :--- | :--- |
| **← / →** | 왼쪽 / 오른쪽 이동 |
| **↓** | 소프트 드롭 (낙하 속도 증가) |
| **↑** 또는 **X** | 시계 방향 회전 |
| **Z** | 반시계 방향 회전 |
| **Space** | 하드 드롭 (즉시 바닥으로 이동 및 고정) |

## ✨ 주요 기능

- **코드 가독성**: 모든 소스 파일(`style.css`, `.ts`) 상단에 파일 경로 주석이 포함되어 있어 구조 파악이 용이합니다.
- **SRS (Super Rotation System)**: 현대 테트리스 표준 회전 시스템을 적용하여, 벽이나 바닥에 막힌 상황에서도 'Wall Kick'을 통해 유연하게 회전할 수 있습니다.
- **7-Bag 시스템**: 7가지 종류의 테트로미노가 한 묶음으로 무작위로 섞여 나옵니다. 이를 통해 특정 블록만 계속 나오거나 오랫동안 나오지 않는 현상을 방지합니다.
- **고스트 피스 (Ghost Piece)**: 블록이 떨어질 위치를 미리 반투명하게 보여주어 정확한 조작을 돕습니다.
- **레벨 및 점수 시스템**: 줄을 지울수록 점수가 올라가며, 10줄마다 레벨이 상승하고 블록의 낙하 속도가 빨라집니다.

## 📂 파일 구조

- `src/`
  - `main.ts`: 게임 초기화 및 이벤트 바인딩 (진입점)
  - `game.ts`: 게임 루프, 7-Bag, 점수 계산 로직
  - `board.ts`: 게임판 관리, 충돌 감지, 라인 삭제, 렌더링
  - `piece.ts`: 테트로미노 데이터 및 SRS 회전 로직
  - `constants.ts`: 설정값 및 킥 테이블 (SRS)
  - `types.ts`: TypeScript 인터페이스 정의
- `js/`: 컴파일된 자바스크립트 파일들이 위치하는 폴더
- `index.html`: 게임 화면 레이아웃
- `style.css`: 게임 디자인 스타일시트
- `tsconfig.json`: TypeScript 컴파일 설정
- `package.json`: 프로젝트 의존성 및 빌드 스크립트 관리
